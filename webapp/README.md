# Aulo 웹앱 (데모)

목적별 공간 추천, Focus·Rest·Suite 예약, 음료 주문을 체험하는 React + Vite 웹앱입니다.
실제 결제·로그인은 없고 예약·주문 기록은 브라우저(localStorage)에만 저장됩니다.

앱 출시를 가정한 프로토타입이라 **반응형을 적용하지 않습니다.** 모든 화면은 모바일 폭(390px) 기준이며,
데스크톱 브라우저에서도 가운데에 390px 앱 화면만 표시됩니다. 390px보다 좁은 폰에서는 화면 폭에 맞춰집니다.

## 실행

```bash
cd webapp
npm install
npm run dev      # 개발 서버 http://localhost:5173
npm test         # 정책 단위 테스트 (Vitest)
npm run build    # dist/ 정적 빌드 (어느 경로에 올려도 동작)
npm run build:artifact  # dist-artifact/ 게시용 빌드 (주소창을 쓰지 않는 메모리 라우터)
```

## 구조

| 경로 | 내용 |
|---|---|
| `src/config/policy.js` | 확정 정책과 임시값. **정책 변경은 이 파일만 수정** |
| `src/lib/reservation.js` | 시작·이용 시간, 마감 제한, 충돌 방지, 요금 |
| `src/lib/order.js` | 주문 유형별 할인 (추가 음료 50%, Suite 리필 순서) |
| `src/lib/recommend.js` | 목적·시간·환경 응답 기반 공간 추천 |
| `src/components/AppShell.jsx` | 앱 바, 하단 탭바(주 메뉴), 햄버거 서랍(마이·보조 메뉴), 하단 액션 바 |
| `src/pages/` | 홈, 공간 추천(질문 3단계), 예약(단계형), 예약 상세, 음료 주문, 내 예약, 주문 내역, 이용 안내 |

## 임시값

`brand-landing/CLAUDE_HANDOFF.md`의 '미확정' 항목은 `provisional()`로 감싼 임시값으로 동작하고,
화면에 `임시` 표시와 하단 '임시 정책 안내'가 나타납니다.

- 오픈 09:00, 예약 가능 기간 14일
- 마지막 종료 22:00 (모든 좌석 22:50 퇴실과 1시간 단위를 맞추기 위함)
- 음료 메뉴: `java-basic/DrinkMenu.java` 구성. 가격은 시장 평균으로 임의 설정(아메리카노 3,000 · 카페라떼 4,000 · 바닐라라떼 4,500 · 허브티 4,000원)
- 좌석 가격: 유사 업종 시장 평균으로 임의 설정(Focus 2,000 · Rest 6,500 · Suite 11,000원/시간). 현장 연장 10분 요금은 시간당 ÷ 6을 100원 단위로 버림(Focus 300 · Rest 1,000원), 연장은 폐점 1시간 전(22:00)까지만, 같은 좌석의 다음 예약과 겹치거나 4시간(최대)으로 예약했으면 연장 불가
- 매장: 성수·연남 대형 카페 2곳, 4가지 공간 모두 운영 (성수 Focus 24 · Rest 18 · Suite 16, 연남 Focus 30 · Rest 20 · Suite 12)
- 할인 쿠폰: Focus·Rest·Suite 예약을 주문에 연결(예약 확인)하면 재주문 혜택을 쿠폰으로 자동 적용. Focus·Rest는 매번 50%, Suite는 무료 리필 → 정상가 → 50% 순서
- Suite 리필: 기본 음료 1잔, 이후 정상가와 50% 할인 교대

## 범위 밖 (1차)

예약 취소, 로그인, 현장 연장, 결제, 마감 알림은 구현하지 않았습니다. 내 예약·주문 내역은 조회만 됩니다.
