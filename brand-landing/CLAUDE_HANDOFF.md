# Claude Code 인계 — Aulo 브랜드 랜딩

## 범위
`index.html`은 CSS, JavaScript, 외부 라이브러리가 없는 시맨틱 HTML 뼈대다. 브라우저에서 바로 열 수 있다. 기존 Java 학습 코드와 자료는 변경하지 않았다.

공개 시안: https://raid-insert-58814555.figma.site/
이번 작업에서는 사이트 조회가 완료되지 않아 대화에 첨부된 모바일 전체 페이지·히어로 이미지와 사용자가 확정한 수정 방향을 기준으로 구조를 작성했다. 최신 사이트와 픽셀 단위 일치를 주장하지 않는다.

## 페이지 구조
헤더 → 히어로 → 브랜드 분위기 → 네 가지 공간 → 공용 야외 라운지 안내 → 이용 절차 및 정책 → 서비스 진입 CTA → 푸터.
원 페이지에서 브랜드와 서비스 소개를 완결한다. 회사 소개 페이지를 추가하지 않는다. 예약 화면 구현은 이번 범위에 포함되지 않는다.

## CSS 작업
- 모바일 390px 우선, 좌우 20px 여백. 큰 영문 제목, 얇은 구분선, 넓은 여백으로 따뜻한 미니멀·에디토리얼 분위기 유지.
- 크림 배경 / 차콜 공간 소개 / 올리브 CTA. 기본 참고값: 배경 #F7F4EC, 텍스트 #302B26, 올리브 #596246, 호버 #444D34, 경계 #D8D0C4.
- 한글 Pretendard, 영문 Manrope. 본문 약 16px, 줄 높이 1.5–1.6. 보조 정보 12–14px. 실제 대비 검수 필요.
- 버튼 높이 48px, 최소 터치 영역 44px. 키보드 포커스, reduced-motion 대응.
- 네 공간 설명은 조작 없이 전부 볼 수 있도록 유지. 가로 슬라이더를 넣더라도 필수 설명을 숨기지 않는다.
- 콘텐츠 높이로 페이지를 구성하고 푸터 아래 긴 빈 공간을 만들지 않는다.
- figure의 `data-asset-slot`은 이미지 자리다. 실제 이미지 확보 시 설명용 figcaption을 적절한 img와 alt로 교체한다. 와이어프레임 스크린샷을 구현 이미지로 쓰지 않는다.
- 기존 원목 사진은 참고 이미지다. Focus는 가림막, Rest는 리클라이너, Suite는 독립된 방이라는 최신 정책과 맞는 사진을 사용한다.

## JavaScript 작업
- 앵커 이동과 details는 기본 HTML로 작동한다. 필요할 때만 JS를 추가한다.
- `data-action="open-service"` 버튼은 현재 비활성이다. 실제 예약 서비스 경로가 준비되면 정상 링크로 교체하고 준비 중 문구를 갱신한다.
- 앱 알림·예약 충돌 검사·음료 혜택 계산은 브랜드 페이지 기능이 아니다. 서비스 구현에서 다룬다.
- 실제 예약처럼 오인되지 않도록 데모 표시 유지. 가격을 온라인 결제금액으로 표시하지 않는다. 방문 후 이용 시작 전 결제다.

## 확정 정책
- Cafe: 음료 주문 후 일반 좌석 이용, 좌석 예약 없음.
- Focus: 1,500원/시간, 이용 전 음료 별도 주문, 좌석별 사물함, 추가 음료 50% 할인.
- Rest: 실내 반폐쇄형 1인 리클라이너만 예약, 3,000원/시간, 이용 전 음료 별도 주문, 사물함, 담요·OTT 이어폰 무료 요청, 추가 음료 50% 할인.
- Focus·Rest: 1시간 단위 최대 4시간. 앱 사전 예약은 현장에서 10분 단위 최대 1시간 연장.
- Suite: 매장별 공간 수 다름. 공간별 가능 시간 조회 및 충돌 방지. 앱 전용, 1시간 단위 최소 3~최대 9시간, 8,000원/시간, 연장 없음.
- Suite: 기본 음료 포함·예약 시 선택, 보관함, 공기청정기, 냉난방, 4구 콘센트. 공간 번호로 음료 배달 주문. 무료 리필 1회 → 정상가 주문 → 다음 주문 50% 할인.
- 취소: 이용 예정일 전날까지만 가능, 당일 불가. 방문 후 이용 전 결제.
- 데모 마감 23:00. Suite 마감까지 3시간 이하 남으면 신규 예약 제한. 22:30 앱 안내, 22:45 이용 중이면 직원 방문 안내, 22:50 퇴실.
- 야외 라운지: 모든 Aulo 이용 고객 공용, Rest 예약에서 제외.

## 미확정 — 임의 구현 금지
1. Suite 1시간 단위 예약과 22:50 퇴실을 맞추는 마지막 시작·종료 슬롯.
2. Suite 기본 음료·리필의 예약당 횟수 기준, 리필 대상 메뉴, 이후 정상가/할인 반복 방식.
3. Focus·Rest 연장 충돌 처리와 10분당 요금의 반올림 기준.
4. 취소 마감 시각, 지각·미방문 정책, 매장 오픈 시간과 음료 메뉴.
5. 로그인·저장·예약내역 기능, 실제 서비스 경로와 문의 채널.

마감 임박 제한을 모든 미래 날짜 예약에 일괄 적용하지 않는다. 예약 생성 시각과 실제 이용 시각을 구분하고 정책 확정 후 검증한다.

## 검수
HTML 구조를 유지하면서 390px에서 제목 줄바꿈, 사진 대비, 네 공간 노출, 주요 CTA, 키보드 탐색을 확인한다. CSS/JS 추가 후 데스크톱과 작은 모바일도 확인한다.
